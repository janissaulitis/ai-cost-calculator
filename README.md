# AI Cost Check

What an AI task really costs to run each month (the AI bill, hosting, and the staff time spent checking its work) against the staff time it frees, with the same task priced on nine current models from Anthropic, Google and OpenAI.

The usual finding: the AI bill is a tiny share of the running cost. Checking the AI's work is the big one, so that's what to design for.

Prices: providers' standard published rates per million tokens, checked 13 Nov 2026 (see `costs.py`, with source links). Token sizes per task are typical estimates and can be changed in the app.

Run: `pip install -r requirements.txt && streamlit run app.py`
